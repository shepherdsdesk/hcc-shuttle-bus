# HCC 셔틀버스 · 할렐루야 셔틀버스 실시간 안내

> 정류장에서 "버스가 지금 어디쯤 왔을까?" 하며 기다리지 않도록.
> 할렐루야교회 셔틀버스가 지금 어디를 지나고 있는지, 언제 도착하는지 휴대폰으로 바로 알려 드리는 웹앱입니다.

- **성도님용**: https://shepherdsdesk.github.io/hcc-shuttle-bus/
- **기사님용**: https://shepherdsdesk.github.io/hcc-shuttle-bus/#driver (운행 번호 필요)

만든 사람 AI목양지원센터 · 이세진 목사 · 문의 contact@mokyangdesk.com

## 운행 노선

| 노선 | 경로 | 운행 |
|---|---|---|
| 야탑역 셔틀 | 야탑역 BYC 앞(2번 출구 신한은행 앞 대로변) ↔ 할렐루야교회 · 중간은 손을 들면 정차 | 주일, 화~토 |
| 파킹엔젤스 | 테크노파크 C동 → 차량등록사업소 주차장 → 할렐루야교회 | 주일 |

## 성도님 사용 방법

1. 위 성도님 주소를 열고 노선(야탑역 셔틀 / 파킹엔젤스)을 고릅니다.
2. 지도에서 버스가 지금 어디 있는지 봅니다. 숫자는 호차 번호입니다.
3. 정류장마다 **도착 예상 시간**이 나옵니다. 위치 신호가 없을 때는 교회 배차 시간표로 다음 출발 시각을 알려 드립니다.
4. 정류장 옆 🔔를 켜 두면 버스가 2~3분 거리에 들어올 때 알림이 울립니다. (화면을 열어 둔 상태에서 동작)
5. **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.
   - 안드로이드: 크롬 ⋮ → 홈 화면에 추가
   - 아이폰: 사파리 공유 버튼 → 홈 화면에 추가 (아이폰은 이렇게 해야 알림이 옵니다)

## 기사님 사용 방법

1. 기사님 주소를 열고 셔틀 담당자에게 받은 **운행 번호**를 입력합니다. (휴대폰마다 처음 한 번만)
2. 노선과 호차를 고르고 **운행 시작**을 누릅니다. 위치 사용을 물으면 **허용**.
3. 화면을 켜 둔 채 거치대에 꽂고 충전기를 연결합니다. 위치가 5초마다 자동으로 올라갑니다.
4. 운행을 마치면 **운행 종료**를 누릅니다.

## 관리자 안내 (Firebase 콘솔 → Realtime Database)

- **운행 번호 바꾸기**: 데이터 탭 `pins` 아래 `번호: true` 항목을 바꿉니다.
- **등록된 기사님 휴대폰 모두 초기화**: `drivers`를 지웁니다. (모두 새 번호를 다시 입력)
- **파킹엔젤스 시간표**: `config/parkTimes`에 `8:00,8:10,8:20`처럼 쉼표로 적으면 바로 반영됩니다.
- **보안 규칙**: `database.rules.json` 내용을 규칙 탭에 붙여 넣고 게시합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (성도님 화면 · 기사님 화면) |
| `sw.js` | 홈 화면 설치 · 알림 표시 |
| `manifest.webmanifest` | 성도님 홈 화면 아이콘 설정 ('HCC 셔틀버스') |
| `manifest-driver.webmanifest` | 기사님 홈 화면 아이콘 설정 ('셔틀 기사님') |
| `icon-*.png`, `apple-touch-icon.png` | 앱 아이콘 |
| `database.rules.json` | Firebase 보안 규칙 |

정류장 좌표, 시간표, 노선 이름은 `index.html` 위쪽의 `ROUTES`, `SUN`, `WEEK`에서 바꿀 수 있습니다.
