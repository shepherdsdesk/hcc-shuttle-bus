## 🚐 기사님 화면

<p>
  <img src="docs/img/driver-setup.jpg" width="230" alt="운행 시작 전">
  <img src="docs/img/driver-live.jpg" width="230" alt="운행 중">
</p>

1. 셔틀 담당자가 보낸 **문자 링크**를 누르면 인증번호가 자동으로 들어갑니다. 휴대폰마다 처음 한 번만 하면 됩니다.
2. "**○○ 기사님, 반갑습니다! 오늘도 안전운전하세요.**" 인사가 화면과 목소리로 나옵니다. 목소리 인사는 하루 한 번이고, 🔊로 다시 들을 수 있습니다.
3. 관리자가 **배정한 차량 하나만** 보입니다. 다른 호차로는 위치를 보낼 수 없습니다 (보안 규칙으로 막아 둠).
4. **운행 시작** → 위치가 몇 초마다 자동으로 올라갑니다. 운행 중에는 **화면이 꺼지지 않습니다.**
5. 종점에 들어오면 회차와 방향이 자동으로 바뀝니다. 화면에는 이번 회차 탑승 인원과 길에서 기다리는 분이 나옵니다.
6. **운행 종료**를 누르면 "운행을 마쳤습니다. 오늘도 수고 많으셨습니다." 안내가 나옵니다.

- 정류장마다 **기다리는 분 인원**이 지도와 화면에 나옵니다. **달리는 중에는 작게** 보이고, 정차하면 크게 보입니다 (운전 중 화면을 들여다보지 않도록).
- 기사님이 운행한 길은 자동으로 기록되고, 관리자가 이 기록을 **노선 줄**로 저장할 수 있습니다.
- 안내 문구는 아이콘 4줄로 짧게 나와 있습니다 (화면 켜 두기 · 충전기 · 다른 앱 주의 · 위치 허용).
- **🔔 소리 점검** 버튼으로 기사님 휴대폰에서 소리가 나는지 바로 확인할 수 있습니다.

## 📺 TV 현황판

<p>
  <img src="docs/img/tv-land.jpg" width="49%" alt="TV 가로">
  <img src="docs/img/tv-xmas.jpg" width="49%" alt="TV 성탄 테마">
</p>

- 지도, 두 노선의 정류장별 도착 시간과 **기다리는 분 인원**, **오늘 운행 시간표**를 함께 보여 줍니다.
- **보여 줄 노선 자동**: 주일에는 야탑역 셔틀과 파킹엔젤스를 함께, 평일에는 야탑역 셔틀만 보여 줍니다 (평일이라도 파킹엔젤스가 실제로 운행하면 함께). 관리자 TV 화면 탭에서 항상 두 노선 / 한 노선만으로도 정할 수 있습니다.
- **평일(한 노선) 화면**: 지도와 도착 시간을 크게, 빈자리는 **⏱ 다음 출발** 카운트다운(방향별 "10:35 · 12분 후")과 넓은 시간표로 채웁니다.
- **📰 행사 포스터 슬라이드**: 운행이 없는 날(시간표에 운행이 없는 날, 관리자가 정한 **쉬는 날**, 그날 **운행이 모두 끝난 뒤**)에는 지도 대신 행사 포스터가 슬라이드로 넘어가고, 옆에 **다음 운행 안내**가 나옵니다. 버스가 실제로 운행하면 자동으로 셔틀 화면으로 돌아옵니다.
- 포스터 액자는 **포스터 대표 색을 자동으로 뽑아** 은은한 바탕을 만들고, 포스터는 둥근 모서리와 그림자로 띄웁니다. 어떤 색 포스터든 화면과 자연스럽게 어울립니다.
- 말씀 칸: **교회 표어**가 늘 위에 보이고, 그 아래 말씀은 관리자가 넣어 둔 **말씀 목록이 매일(또는 매주) 하나씩 자동으로** 바뀝니다. 직접 입력한 말씀 / 표어만 / 숨기기도 고를 수 있습니다.
- 포스터 옆 안내 칸: **다음 운행**과 함께 **이번 주 말씀 · 예배 안내(주일·새벽·수요·금요, 관리자가 이름·요일·시간·장소 칸으로 관리) · 이번 주 셔틀 운행표**(시간표에서 자동)를 10초마다 번갈아 보여 줍니다. **첫차 1시간 전까지**(새벽)도 포스터 화면입니다.
- 관리자 → TV 화면 → **행사 포스터 · 쉬는 날**: 포스터 여러 장 올리기(최대 12장, 권장 1080×1528 · 1080×1080 · 1920×1080), 순서·보이기·보여 줄 기간, 넘김 시간(5~15초), 쉬는 날과 TV 한 줄 안내, "운행이 끝나면 포스터 화면" 켜기/끄기.
- 화면 방향: **자동 / 가로 / 세로 / 세로 회전(↻↺)** 중에 고릅니다. 주소 끝에 `?route=yatap` 또는 `?route=park`를 붙이면 한 노선만 나옵니다.
- **교회 소식 자막**이 아래 띠로 흐릅니다. 빛이 지나가는 효과가 있고, ★ 소식은 강조됩니다.
- **오늘 날씨와 미세먼지**가 나옵니다 (Open-Meteo).
- **절기·계절 테마**: 대림·성탄·사순·부활·추수감사 등은 자동으로 바뀌고 관리자가 직접 고를 수도 있습니다. 계절 효과는 봄 벚꽃, 여름 바람, 가을 낙엽, 겨울 눈입니다.
- 아래에 **셔틀 문의 전화번호**가 크게, 휴대폰 안내 **QR**이 함께 나옵니다.

## 🎨 다른 교회에서 쓰기 (배포 준비)

관리자 페이지 **기본 설정** 탭에서 코드 수정 없이 바꿀 수 있습니다.

- 셔틀 이름 앞 글자 (예: `HCC` → "HCC 셔틀버스")
- 교회 이름, 로고와 로고 배경색
- 관리자 화면 이름·로고 (같은 로고 / 기본 / 따로 올리기)
- 기본 로고 파일 내려받기 (`hcc-shuttle-default-logo.png` 등)

정류장, 노선 줄, 시간표, 차량, 공지, TV 테마도 모두 관리자 페이지에서 정합니다.

---

## ⚙️ 처음 설치하기

1. 이 저장소 파일을 GitHub Pages에 올립니다.
2. Firebase 프로젝트를 만들고 **Realtime Database**, **Authentication**(익명 + Google)을 켭니다.
3. Firebase 콘솔 → Realtime Database → 규칙에 `database.rules.json` 내용을 붙여 넣고 **게시**합니다.
   - 규칙을 새로 올리지 않으면 TV 사진 올리기 같은 새 기능이 "데이터베이스가 맞지 않습니다"라며 막힙니다.
4. 처음 관리자 한 명만 Firebase 콘솔에서 직접 등록합니다 (관리자 페이지에 로그인하면 방법이 나옵니다). 그다음부터는 관리자 탭에서 추가합니다.
5. (선택) 카카오 개발자 사이트에서 JavaScript 키를 받아 관리자 페이지 지도 설정에 넣습니다. 사이트 도메인에 GitHub Pages 주소를 등록해야 합니다.

## 📁 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 성도님 화면 (+ 기사님 화면 코드) |
| `driver.html` | 기사님 화면. index.html과 같은 앱이고 홈 화면 아이콘만 기사님용 |
| `admin.html` | 관리자 페이지 |
| `tv.html` | TV 현황판 |
| `sw.js` | 홈 화면 설치 · 알림 |
| `manifest*.webmanifest` | 홈 화면 아이콘 설정 (성도님 / 기사님) |
| `icon-*.png`, `apple-touch-icon*.png` | 앱 아이콘 (성도님 남색 · 기사님 주황 · 관리자 진회색) |
| `hcc-logo-*.png`, `hcc-shuttle-default-logo.png` | 교회·셔틀 로고 파일 |
| `database.rules.json` | Firebase 보안 규칙 |
| `docs/img/` | 이 설명서에 쓰인 화면 그림 |

## ❓ 자주 묻는 질문

**소리가 안 나요.**
→ 화면의 **🔔 소리 점검**을 눌러 보세요. 결과에 맞는 해결 방법이 나옵니다. 흔한 원인은 세 가지입니다.
- 카카오톡·네이버 앱 안에서 열었다 → 크롬으로 열기
- 미디어 볼륨이 0이다
- 기기에 한국어 읽어 주기(TTS)가 없다 → Play 스토어에서 "Google 음성 서비스"를 설치하고 한국어로 설정

목소리가 안 나와도 **딩동** 소리는 거의 모든 기기에서 납니다.

**기사님 인사 목소리가 두 번째부터 안 나와요.**
→ 하루 한 번만 나오는 게 정상입니다. 🔊 버튼으로 다시 들을 수 있습니다.

**한 자리에서 테스트하면 "곧 도착" 알림이 안 울려요.**
→ 버스가 실제로 정류장 쪽으로 **다가와야** 울립니다. 반대편 도로를 지나가는 버스를 잘못 알리지 않으려고 넣은 기능입니다.

**테스트 기록을 지우고 싶어요.**
→ 관리자 → 통계 → **운행기록 초기화**. 지우기 전에 백업 파일이 자동으로 저장됩니다.
